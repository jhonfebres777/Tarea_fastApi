## Requisitos

- Python 3.14.4
- MongoDB 4.0+

## Instalación

1. Clonar el repositorio
2. Crear entorno virtual: `python3 -m venv env`
3. Activarlo: `source env/bin/activate`
4. Instalar dependencias: `pip install -r requirements.txt`

## Ejecución

uvicorn app:app --reload
